# Changelog

## 5.1.0
- Image par click karte hi image clipboard me copy ho jati hai.
- Saari files ek hi level par (koi folder nahi): `app.html` ab `index.html`, icons aur screenshot root me. GitHub Pages ab bina Actions ke, "Deploy from a branch" se free chalta hai.
- EOD image ka margin aur padding har taraf se zero.

## 5.0.0
- **Set as default**: Style drawer me apna design (colour, font, size, layout, columns) "Set as default" se save karo. Pehli baar kholne par aur "Default" dabane par wahi design lagta hai. "Factory" se original design wapas.
- **Grand Total + Additional Work neeche fixed**; Platform data me sirf platform cards scroll hote hain.
- Copy image, Download PNG, History aur Save to History hata diye.
- **Auto-sync**: data har second apne-aap save hota hai aur dobara kholne par wahin se khulta hai (date bhi).
- **Reset data**: sirf data saaf karta hai (numbers, Grand Total, Additional Work, date = aaj). Design, columns, naam aur platform selection nahi badalte.
- Personal default naam / Additional Work text hata diya (sab users ke liye khali shuru hota hai).
- Web version: GitHub Pages par seedha browser me chalta hai (extension install ki zaroorat nahi).

## 4.1.0
- Platform data: zyada rows hone par wapas slide (scroll) hota hai, zoom/compact mode hata diya.
- Teeno sections ke beech ke divider ko drag karke chhota/bada karo (double-click = default, size yaad rehta hai).
- Platform buttons (chips) ab card ki poori chaudai bharte hain.
- Columns ab Details me neeche, vertical aur 1, 2, 3... number ke saath (▲▼ order, + nayi column).
- Image: EOD line aur neeche ki border line ke beech gap zero.
- Naye default colours: Multi colour on, Shades, Spread 0%, Background Tint.

## 4.0.0
- **Column order manager**: columns ko ‹ › se aage-peeche karo, har jagah (beech me bhi) `+` se nayi column jodo, extra column hatao. Values column ke saath hi move hoti hain.
- **Multi colour ab main colour se bante hain** (UI aur image dono): Analogous / Shades / Complementary / Triadic / Split rang-mel + Spread slider.
- **Style drawer me 4 tabs** (Colour, Text, Layout, Show) aur bahut saare chhote options: ready colour dots, background, font + size (5% step) + bold har section ke liye, row height / gap / roundness / shadow, image quality (1x-3x), naam ki jagah, aur 6 show/hide toggles.
- **Sab kuch screen me fit**: koi section scroll nahi hota. Bahut platforms ho to automatic compact "sheet" mode.
- Purana saved data aur history automatically naye format me convert hota hai.
